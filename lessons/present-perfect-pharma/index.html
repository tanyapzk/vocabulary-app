Resultorprocess?

Present Perfect or Present Perfect Continuous. Understand the difference once, then use it in real work talk.

Speak

  4. What is one thing you have achieved this year?
  5. What have you been finding difficult lately?

Questions 1 and 4 ask about a result. Questions 2, 3 and 5 ask about an activity over time. That is today's whole topic.

02

The big idea in one picture

Both tenses connect the past with now. The difference is what you want to talk about.

Present Perfect

RESULT

have / has + V3

The action is done, and the result matters now. We care about what and how many.

I've tested 40 samples.

Present Perfect Continuous

PROCESS

have / has been + V-ing

We care about the activity itself: how long, how it is going, what we can see now.

I've been testing samples since 8 a.m.

Quick test: "How many?" points to the result. "How long?" points to the process.

04

Forms and signal words

The forms are easy. Signal words help, but the meaning decides.

Present Perfect

PositiveI've tested · she's tested
NegativeI haven't tested · she hasn't tested
QuestionHave you tested…? How many have you tested?

Present Perfect Continuous

PositiveI've been testing · she's been testing
NegativeI haven't been sleeping well
QuestionHave you been testing…? How long have you been testing?

Often Present Perfect

alreadyyetjustever / neverso farhow many

Often Continuous

all day / all morninghow longlately

05

Exceptions and traps

This is where most mistakes live. Read each card, then make your own sentence with it.

One sentence per card
A

Stative verbs have no continuous

know, be, have (own), like, want, need, believe, understand, belong

I've known the director for years.I've been knowingI've been in pharma for 8 years.
B

live, work, study: both are fine

Almost no difference. The continuous sounds a bit more temporary or recent.

I've lived in Moscow for 5 years.I've been living in Moscow for 5 years.

"All my life" is only Present Perfect.

C

A number means a result

With a count, use Present Perfect. Career summaries too.

I've written five reports.I've been writing five reportsI've worked for three pharma companies.
D

Evidence you can see or feel

An activity left a trace? Continuous. A finished object? Perfect.

You're out of breath. Have you been running?Look! I've found the mistake.
E

Finished or not finished?

Perfect: it's done. Continuous: it may not be.

I've read the protocol. (done)I've been reading the protocol. (still going?)
F

Finished time word = Past Simple

yesterday, last week, in 2019, three days ago

We submitted the file last week.We have submitted the file last week

Repeated activity lately: "I've been getting a lot of calls."

13

Cheat sheet

Keep this page for yourself. Next time we'll check how much you remember.

RESULT

have / has + V3
  • done, and it matters now
  • how many, how much
  • news, a finished thing you can see
  • already, yet, just, so far

PROCESS

have / has been + V-ing
  • the activity itself
  • how long, all day, lately
  • a trace you can see or feel
  • maybe not finished
Remember: know, be, have, like, want → no continuous. A finished time (yesterday, in 2019) → Past Simple. live / work / study → both are fine.
