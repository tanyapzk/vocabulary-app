# Vocabulary App

Interactive vocabulary practice pages for English students. Each page is a single self-contained HTML file with flashcards, multiple choice, matching, a written test and progress analytics.

The site is published with GitHub Pages: https://tanyapzk.github.io/vocabulary-app/

## Adding a new page

1. Create a folder named after the student (for example `anna/`).
2. Put the practice page inside it as `index.html`.
3. Commit to `main`. The page will be live at `https://tanyapzk.github.io/vocabulary-app/anna/` within a minute or two.
